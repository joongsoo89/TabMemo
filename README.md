# TabMemo

대주제를 만들고, 그 안에 탭을 나눠 메모하는 안드로이드 앱입니다.

Made by Tokyoromance

## APK 설치

1. 이 저장소의 [`releases/TabMemo-debug.apk`](releases/TabMemo-debug.apk)를 받습니다.
2. 안드로이드 폰에서 파일을 열고 설치합니다.
3. 처음이면 **알 수 없는 앱 설치**를 허용해야 할 수 있습니다.

## 앱 기능

- 대주제(메인 메모) 아래에 탭을 추가해 메모를 분류
- 탭 추가/이름 변경/삭제는 편집 화면에서만 가능
- 메모에 사진 첨부, 사진을 눌러 원본 보기와 확대
- 라벨을 붙여 라벨별로 목록 검색/필터
- `.tabmemo` 파일로 가져오기/내보내기 (사진 포함)
- 화면 언어: 한국어 / 日本語 / English

## 업데이트

### 2026-09-06

- 편집을 누르면 보고 있던 탭부터 열고, 저장하면 그 탭 보기 화면으로 돌아갑니다.
- 보기 화면의 URL을 눌러 브라우저로 열 수 있습니다.
- 보기 화면에서 글을 길게 눌러 복사하거나, 복사 버튼으로 복사할 수 있습니다.
- 공유 버튼으로 카카오톡, 라인, 메시지, 메일 등에 현재 탭 내용을 보낼 수 있습니다.
- 헤더와 기능 버튼은 고정하고, 긴 메모는 본문 영역에서만 스크롤합니다.
- 사진 추가 아이콘을 더 작게 만들었습니다.

### 2026-09-05

- 탭은 보기 화면에서 확인만 하고, 추가·이름 변경·삭제는 편집 화면에서만 하도록 바꿨습니다.
- 메모에 사진을 올릴 수 있습니다. 추가 버튼은 카메라 아이콘입니다.
- 사진을 누르면 전체 화면에서 원본 비율로 보고, 두 손가락으로 확대하거나 두 번 탭해 확대할 수 있습니다.
- 라벨을 붙이고, 목록에서 라벨을 눌러 그 라벨 메모만 볼 수 있습니다.
- 파일 가져오기/내보내기를 지원합니다. 사진이 있으면 함께 저장됩니다.
- 화면에 Made by Tokyoromance 문구를 넣었습니다.
